# 离线试卷语料

[二年级上册：试卷目录与使用说明](grade-2/semester-1/README.md)

本目录保存网上公开可访问的地区期末试卷转载件，供离线选题与训练设计。原卷、参考答案、来源页面快照和元数据一起保存。来源标为地区考试卷不等于已获得命题单位的真实性认证。

选题先看目录中的教材版本、学年和答案状态，再打开原卷。提取文字只供搜索，数学图形、数值、拼音、标点、下划线以及答案必须回看原件。历史卷需要对照孩子当前使用的教材，不可直接把整卷当作当前教学范围。

新增材料沿用 `grade-N/semester-N/学科/材料ID/`；保留原始文件，不用机器识别结果覆盖。付费、登录或预览不全的材料应明确标记，不把预览充当完整卷。
