# 读懂再答：25题分类练习

取消三轮、验证题和综合测试安排，改为按题型自由选择的25道短题。所有题型和题目从首次打开起均可进入，不要求完成前题或交整组试卷。

## 题库

| 题型 | 数量 | 稳定题号 |
| --- | ---: | --- |
| 看清所问 | 3 | T06、T26、T46 |
| 完整作答 | 4 | T01、T12、T32、T56 |
| 信息判断 | 4 | T03、T19、T30、V15 |
| 指代理解 | 3 | T02、T42、X03 |
| 多步计算 | 3 | T15、V02、T55 |
| 顺序排列 | 3 | T09、T40、T49 |
| 整体概括 | 3 | T04、T24、T54 |
| 问法等价 | 2 | T07、T47 |

按主要任务给每题唯一分类，保留原有能力标签供材料维护。题目从90道短题中选择，保留短材料、题干、选项、答案、解析和注音；不按旧轮次等级选择，也不把旧题号重新编号。V15、X03、V02的稳定题号保留，现均作为普通训练题，提供数项和依据标记。

分类清单见[categories.json](../materials/read-before-answer/categories.json)，旧90道短题完整快照见[bank-2.0.json](../materials/read-before-answer/bank-2.0.json)。[生成工具](../tools/build-reading-bank.py)根据清单及原有短材料源稿生成现行25题，不把归档旧题重新展示在练习中。

## 操作与记录

- 首页按题型展示完成进度；进入题型后可选择任意一道题。
- 各题草稿分别保存，切换题型和题目不清空其他题的未完成答案；刷新后可继续。
- 提交本题后立即查看反馈，无整组交卷或解锁条件。
- 已完成题可查看首次结果或再练一次。重练单独记录，不覆盖首次答案和正确率。
- 原有精简文案和公共上方注音继续使用，不增加版本切换说明。

## 版本与迁移

当前数据结构为`version: 2`、题库为`3.0`，进度键为`brison-tutor:progress:read-before-answer:v2`。

首次从90道短题切换时，读取旧键`brison-tutor:progress:read-before-answer:v1`，只迁移仍保留且原本就是训练模式的有效首次记录和当前草稿。先在内存验证新结构，再写入新键，原键始终保持原样，兼作迁移备份。删去题目及旧验证、测试的记录留在原键，不凭空补数项或信息标记成绩。更早的长材料键`reading-lab-v1`也保持原样。

迁移成功后保存隐藏标记`brison-tutor:progress:read-before-answer:migration:v1-v2`，在`catalog.js`的`storage.auxiliaryKeys`登记。统一管理页不将其列成一条答题记录；清理当前版本时保留该标记，避免下次打开又恢复已清理成绩。清理整个练习或全部进度时，同时删除该练习的旧记录及隐藏标记。

不兼容或损坏的当前记录、迁移源记录原样保留，暂停覆盖保存并提供故障导出；空字符串也按损坏数据处理。导入备份覆盖已有或损坏记录前均确认，取消不改原数据。此处规则也适用于后台结构损坏、但版本号仍正确的记录。
