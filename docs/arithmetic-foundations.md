# 乘除意义与运算顺序

[互动练习](../dist/exercises/grade-2/semester-1/math/arithmetic.html) · [题库、答案与解析](../dist/exercises/grade-2/semester-1/math/arithmetic-bank.js)

十类题在同一轮交错出现，每类六题。孩子作答时只看题目。每类连对两道符合要求的题便停止出这一类，答错只重置本类。十类都达标后显示本轮记录。

## 判题要点

| 训练内容 | 类别 | 达标覆盖 |
| --- | --- | --- |
| 选对运算 | 每份一样多，求总数 · 已知份数，求每份 · 已知每份，求份数 · 用加减求合计或相差 | 每类各做对一道看故事选算式、一道看算式选故事。 |
| 选对运算 | 用除法编题 | 先做一道选问句的示例。正式题须选两条条件、所求量和带单位的算式。两道连对题须分别问每份多少、能分几份。 |
| 先算哪一步 | 乘法优先 · 除法优先 | 所选运算符、中间数、最后结果均须正确。同一类的两道连对题须分别覆盖优先项在左、在右。 |
| 先算哪一步 | 同级加减从左往右 · 同级乘除从左往右 · 小括号优先 | 各做对两道不同的题，每道的三个步骤均须正确。 |

运算顺序题先选运算符，再算画线部分。确认中间数后，页面把画线部分替换成这个数，孩子用改写后的短算式算最后结果。前两步答错时显示正确步骤并继续，轮末分别统计顺序、中间数和最后结果的错误。

编题成绩反映孩子在给定选项下的拼题表现。轮末汇总分别记录条件、问句和算式选错的次数。
